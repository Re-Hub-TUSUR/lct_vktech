# Скиллы и агенты пайплайна

Каждый файл `*.yaml` описывает один скилл или агента пайплайна: промпты, параметры,
модель и **версию**. Код читает эти файлы через `app/pipeline/skills.py`, поэтому
промпты и конфиги не зашиты в код (требование ТЗ).

При каждом прогоне генерации снимок версий всех скиллов сохраняется в
`generations.skills`. По нему видно, какой версией пайплайна собрана презентация,
и можно сравнивать результаты разных версий.

## Формат

```yaml
name: outline_planner        # уникальный идентификатор, по нему скилл вызывается из кода
title: Планировщик структуры # название для интерфейса
version: 0.1.0               # semver; меняйте при любом изменении промпта или параметров
kind: skill | agent
runtime: code | mock | llm | vlm | t2i   # как исполняется сейчас
stage: outline               # стадия пайплайна (app/pipeline/stages.py)
model: null                  # модель, если нужна (открытые веса, Apache 2.0 / MIT, ≤ 35B)
description: ...
prompt:                      # опционально: system / user
  system: ...
  user: ...
params: {}                   # параметры, которые читает код стадии
```

`runtime: mock` означает, что сейчас стадия — заглушка с детерминированным результатом,
а промпт — задел для подключения LLM.

## Шаблонные пользовательские скиллы (`presets/`)

Папка `presets/` — стандартная комплектация пользовательских скиллов (разговорный стиль,
подача для молодёжи, сторителлинг и т. д.). Это не стадии пайплайна, а готовые
инструкции, которые пользователь включает тумблером в настройках презентации или
копирует в свою библиотеку для правки. Отдаются эндпоинтом `GET /api/skills/presets`,
в снимке прогона получают id вида `preset:<id>`.

```yaml
id: conversational           # уникальный идентификатор
title: Разговорный стиль
version: 1.0.0               # меняйте при правке инструкции
kind: all | text | design | audit   # на какие стадии влияет
description: ...             # одна строка для интерфейса
instruction: |               # текст, который получают агенты
  ...
```

Не сочетайте в инструкции слова «заголовок» и «вопрос»: детерминированное правило
`apply_custom_style_rules` (audit/fixes.py) тогда превратит все заголовки в вопросы.
