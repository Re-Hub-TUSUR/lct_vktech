Поддержать форматы `.json`, `.yaml`, `.yml` в контент-пакете. Реализовать извлечение структурированных данных (ключевые параметры, числовые метрики, списки) в текстовый дайджест фактов для использования моделью при генерации контента слайдов.

В модуле экспорта (`pptx_export.py`) поддержать вставку изображений, привязанных из контент-пакета презентации, в файл PowerPoint наравне с пользовательскими изображениями.

В редакторе слайдов (`AuditPage.tsx` / тулбар) предоставить возможность выбора изображения из уже загруженных в контент-пакет картинок.
