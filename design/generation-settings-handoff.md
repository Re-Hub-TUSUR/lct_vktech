# Handoff: «Новая презентация» (настройки генерации), редизайн

## Overview
Переделка `PresentationSettingsPage.tsx` (`styles/pages/settings.css`). Сейчас это пять пронумерованных карточек подряд. Главное поле (название) спрятано под галереей шаблонов, самое ценное (бриф и материалы) разнесено по двум карточкам, а параметры и скиллы занимают больше места, чем то, о чём презентация.

Новая логика: сначала **о чём** (название, бриф, материалы), потом **как оформить** (шаблон), потом **тонкая настройка** (свёрнуто по умолчанию). Справа закреплена панель **«Готовность»**: там видно, чего не хватает, и оттуда запускается генерация.

Стек: React 19 + TS, токены `tokens.css`, компоненты `ui.tsx` (`Button`, `Select`, `Segmented`, `Toggle`, `Field`, `Badge`), `lucide-react`. Поток данных прежний: `SettingsForm`, `PresentationInput`, `FileDrop`, `SkillsPicker`/скиллы по умолчанию.

- Карточки: `--color-surface`, 1px `--color-border`, radius 20, padding 28, gap между карточками 20.
- Нумерацию «1–5» убрать. Заголовки карточек: VK Sans Display 600, 20px. Под заголовком одна строка 14px `--color-text-muted`.

## A. О чём презентация
- **Название**: без отдельного лейбла, как заголовок документа. Input без рамки, VK Sans Display 600 26px, placeholder «Название презентации». Снизу 1px `--color-border`, на фокусе `--color-primary`. `autoFocus` для новой презентации.
- **Бриф**: textarea на всю ширину, 8 строк, min-height 180, radius 12, фон `--color-canvas`. Placeholder: «Что за продукт или проект, для кого презентация, ключевые тезисы, цифры и выводы…». Под полем слева `N / 20 000`, справа «Цифры из брифа аудит считает подтверждёнными».
- **Материалы** (бывший «Контент-пакет») встроены прямо под брифом:
  - строка `Paperclip 16` + «Приложить материалы» (ghost-кнопка) + «PDF, DOCX, PPTX, XLSX, CSV, изображения…»;
  - drag-and-drop на всю карточку A: при `dragover` карточка получает 2px dashed `--color-primary` и оверлей «Отпустите, чтобы приложить»;
  - файлы показываются чипами (иконка по категории, имя с ellipsis до 220px, размер, ×). У картинок вместо иконки миниатюра 24×24 radius 4. Загрузка: чип с прогресс-полосой 2px.
- **Строка из двух колонок** (`1fr 1fr`, gap 16):
  - «Назначение»: `Segmented` (Фича / Продукт / Проект / Инициатива);
  - «Аудитория»: input с placeholder «Кому показываем: комитет, клиенты…».

## B. Шаблон
- Вместо сетки 3×2 на весь первый экран: **горизонтальная лента** мини-обложек (ширина 168, 16:9, radius 10, gap 12, overflow-x auto со scroll-snap).
- Выбранная обложка: 2px `#0077ff` + `0 0 0 3px rgba(0,119,255,.25)`, в углу галочка 20px на primary.
- Под лентой строка выбранного шаблона: имя (600 15px), палитра (8 кружков 14px), «39 макетов · 54 слайда · 16:9», ссылка «Дизайн-система шаблона →».
- Последний тайл: «+ Свой .pptx» (dashed, того же размера), как в `TemplateUploader`.
- Кнопка «Все шаблоны» (ghost, справа в заголовке) открывает `Modal` с текущей сеткой `TemplateCard`, если шаблонов больше 6.
- Шаблон в статусе `processing`: обложка со `Skeleton`, `Spinner` и подпись «Разбираем шаблон…». Выбрать такой шаблон нельзя.

## C. Параметры (свёрнуто по умолчанию)
- Заголовок-аккордеон: «Параметры» и справа сводка 13px muted «12 слайдов · русский · деловой · плотность контента». Chevron 16 поворачивается на 180°, `--dur-base`.
- Внутри:
  - **Объём**: `Segmented` из пресетов «Коротко 8 · Стандарт 12 · Подробно 15» и ещё «Своё…». «Своё…» открывает number-stepper (− N +) в диапазоне `options.slides_count.min–max`. Слайдер убрать: у него не подписаны края.
  - **Язык** и **Тон** в одной строке, оба `Segmented`. Тон из трёх значений, выпадающий список для него лишний.
  - **Чем отличаются три варианта**: 4 радио-карточки в сетке **2×2**, без висящей четвёртой. Карточка: заголовок 600 15px, описание 13px muted, затем одна строка «A Лаконичный · B Сбалансированный · C Подробный» (12px, `--color-text-subtle`, буква primary). Сейчас это чипы, и они выглядят кликабельными. Выбранная карточка: primary-border + primary-soft фон + радио-точка слева вверху.
  - **Тумблеры**: «Заметки докладчика» и «Генерировать изображения». У второго `disabled` и `Badge` «скоро» вместо текста про «задачу со звёздочкой».

## D. Скиллы (свёрнуто, если ничего не включено)
- Заголовок: «Скиллы» и справа «2 включено» или «по умолчанию не выбраны».
- Внутри **чипы** вместо строк по 100px: `pill`, 32px, «Для руководства v1.0.0». Включённый чип: primary-soft/primary. Наведение показывает tooltip с описанием.
- Группы «Моя библиотека» и «Стандартные» в две строки чипов. «Разовые правила» уходят под кнопку «+ Разовое правило».
- Скиллы, включённые по умолчанию на странице «Скиллы», уже включены (это сделано в `SkillsPicker`/`skillSnapshot`).
- Ссылка «Управлять библиотекой →».

## Панель «Готовность» (sticky, top 88)
Карточка radius 20, padding 24, gap 16.
1. **Обложка выбранного шаблона**: 16:9, radius 10, поверх неё название презентации (или плейсхолдер «Название появится здесь»). `SlideView` обложки с `title`, как на карточке шаблона.
2. **Чек-лист**, строки 13.5px: иконка 16 (`CircleCheck` success / `Circle` subtle / `CircleAlert` warning) и текст:
   - «Шаблон: VK Tech»;
   - «Название»: если пусто, строка кликабельна, фокусирует поле и прокручивает к нему;
   - «Бриф или материалы» (рекомендуется): warning с подсказкой «Без материалов модель возьмёт только тезисы брифа»;
   - «12 слайдов · 3 варианта: плотность контента».
3. **Варианты A/B/C**: три строки «A · Лаконичный» (буква в кружке 20px primary-soft).
4. **CTA** «Сгенерировать 3 варианта» (`Button lg`, на всю ширину, `Sparkles`).
   - Неактивна: фон `--color-surface-muted`, текст `--color-text-subtle`, без тени. Сейчас кнопка остаётся синей и выглядит активной.
   - Над ней строка причины: «Добавьте название, чтобы запустить».
   - Existing + `isGenerating`: как сейчас, ссылка «Открыть прогресс».
   - Перегенерация уже сгенерированной: подпись «Текущие варианты и правки будут заменены» (warning 12.5px).
5. Под кнопкой: «Обычно 3–5 минут — прогресс каждой стадии видно на следующем шаге». Без «по ТЗ».
6. «Папка проекта»: компактный `Select` внизу панели («Папка: Без папки ▾»), а не отдельное поле в форме.

## Состояния и поведение
- **Горячая клавиша** Ctrl/Cmd+Enter из любого поля запускает генерацию, если кнопка активна.
- **Черновик формы**: автосохранение в `localStorage` по ключу `settings.draft.new`, чтобы не терять бриф при случайном уходе. Очищать после успешного создания.
- **Ошибки**: при ошибке API под CTA показывается `ErrorState` (как сейчас). Ошибка загрузки отдельного файла показывается на его чипе (danger-border + tooltip).
- **Режим «только просмотр»** (viewer): все поля `readOnly`, CTA скрыт, в панели бейдж «Только просмотр».
- **Редактирование существующей**: заголовок «Настройки презентации», блок C раскрыт.

## Мелочь вне страницы
